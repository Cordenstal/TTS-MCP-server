# Kill Team rules/context

This directory is reserved for the host-managed context for the
`Kill Team 3.0 Quick and Easy` variant used by the first semantic opponent.

The executable adapter, not this Markdown file, is authoritative for legality.
Before autonomous play is enabled, populate `rules.md` with the approved
variant rules, setup conventions, visibility limits, terrain semantics, dice
workflow, scoring, and host-ruling policy. Do not place concealed opponent
state or private setup data here.

The implementation contract is documented in the
[Kill Team wiki page](../../docs/wiki/killteam.md) and
[ADR-0009](../../docs/adr/0009-killteam-semantic-opponent.md).
